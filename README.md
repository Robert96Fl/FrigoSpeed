FrigoSpeed

FrigoSpeed** este o aplicație web concepută pentru gestionarea, optimizarea și calculul rutelor rutiere de transport (specializată pentru flote de transport frigorific / marfă). (Orice idee noua este binevenita de imbunatatire si optimizare)

---

 Tehnologii utilizate

-Frontend:HTML5, CSS3, JavaScript
Backend: Node.js, Express
APIs / Utilitare: Calcul rutier și distanțe în kilometri / Lupa GPS deja integrata cu un refresh rate la 30 secunde . 

---

Funcționalități curente

- 📍 Calcularea rutelor rutiere și a distanțelor în kilometri.
- 🚛 Monitorizarea și selectarea camionului / numărului de înmatriculare.
- 💻 Interfață simplă și rapidă pentru dispecerat și transportatori.



 Unde trebuie sa ajungem: 


🔐 System de autentificare (Login / Register) pentru dispeceri și șoferi.
🗺️ Integrare avansată cu hărți interactive (ex. Leaflet / Google Maps API).
📊 Modul de generare rapoarte de consum și cheltuieli per cursă.
📱 Optimizare și adaptare completă pentru dispozitive mobile (Responsive Design).
📱Salvarea permanentă a datelor într-o bază de date (ex. MongoDB sau PostgreSQL).
